# 2-11. 불균형을 줄이는 방법마다 잃는 것이 다르다

## 문제

[2-5](2-5.md) 에서 "불균형 데이터는 AI의 판단을 왜곡한다"를 **측정**했다.
그 다음에 오는 질문은 하나다.

> "그래서 어떻게 하죠?"

검색하면 "오버샘플링 하세요"가 나온다. 그런데 방법마다 대가가 다르다.

## 실습

```bash
pytest -m lesson_2_11 -s
```

## 다섯 가지를 나란히 놓는다

```text
NONE          6,048 →  6,048행  불균형 35.1배 → 35.1배
CLASS_WEIGHT  6,048 →  6,048행  불균형 35.1배 → 35.1배
OVERSAMPLE    6,048 → 15,354행  불균형 35.1배 →  1.0배  복제 9,306
UNDERSAMPLE   6,048 →    438행  불균형 35.1배 →  1.0배  버림 5,610
SYNTHETIC     6,048 → 15,354행  불균형 35.1배 →  1.0배  합성 9,306
```

'아무것도 하지 않는다'도 하나의 전략이다.
**그것과 비교하지 않으면 좋아졌는지 알 수 없다.**

## 복제는 표본을 늘리지 않는다

```text
WARNING REBALANCE_HEAVY_DUPLICATION
        같은 표본을 평균 64.7배로 늘렸다.
        **서로 다른 표본은 여전히 146개뿐이다** —
        모델은 그 몇 개를 외운다.
```

표에서는 비율이 완벽하게 맞았다. **그런데 새 정보는 한 줄도 늘지 않았다.**
학습 정확도만 올라가고 검증은 안 따라온다 ([3-7](3-7.md)).

## 버리기는 정상의 다양성을 버린다

```text
WARNING REBALANCE_HEAVY_DISCARD
        5,610행(93%)을 버렸다.
        **현장의 '정상'은 한 가지가 아니다** —
        버린 것 중에 다음 달에 필요할 정상이 있다.
```

그리고 버린 데이터는 되돌릴 수 없다.

## 가중치는 아무것도 잃지 않지만 아무것도 얻지도 않는다

```text
INFO REBALANCE_WEIGHT_ONLY
     가중치는 데이터를 건드리지 않았다.
     **시험지 유출도 없고 버린 것도 없다** — 그래서 대개 여기서 시작한다.
     다만 없는 것은 여전히 없다.
```

모듈 3 의 `class_weighted_loss` 가 이것이다.

## 가장 중요한 한 줄

```text
CRITICAL REBALANCE_BEFORE_SPLIT
         분할하기 **전에** 리샘플링했다.
         복제된 표본이 train 과 test 양쪽에 들어간다 —
         **정확도는 올라가고 현장에서는 그대로다.**
```

이 실수는 **지표가 좋아지기 때문에 아무도 의심하지 않는다.**

```text
분할 후 적용 : WARNED
분할 전 적용 : BLOCKED
```

같은 전략, 적용 시점만 다르다.

## 어떤 리샘플링도 표본 부족을 고치지 못한다

```text
CRITICAL REBALANCE_CANNOT_FIX_SHORTAGE
         가장 적은 클래스의 서로 다른 표본이 12개다.
         **어떤 리샘플링도 이 숫자를 늘리지 못한다.**
```

FAULT 12장을 8,000장으로 늘렸다. 표에서는 완벽하다.
**그러나 이 모델이 아는 고장은 여전히 12가지다.**

비율을 맞춰서 지표가 좋아 보이면 "데이터를 더 모아야 한다"는 결론이 가려진다 —
그게 진짜 손해다.

## 자주 하는 실수

- **오버샘플링부터 한다.** 가중치가 잃는 것이 가장 적다.
- **분할 전에 리샘플링한다.** 시험지가 유출된다.
- **비율만 본다.** 서로 다른 표본 수를 함께 봐야 한다.
- **기준선을 안 만든다.** 아무것도 안 한 결과가 없으면 비교가 아니다.
