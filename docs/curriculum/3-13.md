# 3-13. 통계로 잡히는 이상을 AI라고 부르지 마라

## 문제

AI 프로젝트를 시작하기 전에 반드시 물어야 하는 질문이 있다.

> **"이거, 통계로는 안 되나?"**

3-시그마 규칙은 1920년대 공장에서 쓰던 것이다.
학습이 없고, GPU 가 없고, 왜 그렇게 판단했는지 한 줄로 설명된다.
그것으로 끝나는 문제에 신경망을 얹으면 **유지비만 평생 늘어난다.**

## 실습

```bash
pytest -m lesson_3_13 -s
```

## 같은 자리에서 잰다

통계 검출기를 **같은 데이터·같은 창·같은 혼동 행렬**로 돌린다.
그리고 AI 쪽 결과를 '이상 여부'로 접는다 — 접지 않으면 공평하지 않다.

```text
[이상 여부만 놓고 비교]  검출기 THREE_SIGMA(k=3, 창 비율≥0.2)
                                 재현율       정밀도
통계 기반                        0.214     1.000
학습 모델                        1.000     1.000
```

## 본론 (1) — 통계는 둘을 동시에 갖지 못한다

```text
     k      재현율      정밀도
   1.0     1.000     0.212
   1.5     0.929     0.342
   2.0     0.286     1.000
   3.0     0.214     1.000
```

k=1.0 이면 다 잡지만 **알람 5건 중 4건이 헛것이다.**
현장은 그런 알람을 일주일이면 꺼 버린다 ([5-13](5-13.md)).
k=3.0 으로 조이면 헛알람은 사라지지만 21% 밖에 못 잡는다.

AI 는 재현율 1.000, 정밀도 1.000 이다.

## 본론 (2) — 통계는 유형을 말하지 못한다

```text
이상 여부만  : 통계 0.214 / 모델 1.000
유형까지     : 통계 —      / 모델 1.000 (유형 2종)
```

FAULT 와 OVERLOAD 는 **대응이 다르다.**
하나는 설비를 세워야 하고 하나는 부하를 낮추면 된다.

"평소와 다르다"만 알려 주는 알람으로는 사람이 뛰어가서 눈으로 봐야 한다.

> **AI 를 쓸 근거는 정확도가 아니라 여기에 있다.**

## 이기지 못하면 멈춘다

```text
CRITICAL BASELINE_NOT_BEATEN
         학습 모델이 통계 기준선을 재현율에서 +0.020 밖에 못 이겼다.
         **이 정도면 3-시그마 한 줄로 끝낼 문제다** —
         신경망은 학습·변환·배포·재학습 비용을 평생 데리고 다닌다.
```

여기서 멈추는 판단이 프로젝트를 살린다.

## 세 규칙은 가정이 서로 다르다

```text
THREE_SIGMA  정규분포를 가정한다. 현장 신호는 대개 정규분포가 아니다.
IQR          분포 모양을 가정하지 않는다. 치우친 신호에 낫다.
EWMA         **기준선이 천천히 따라 움직인다.**
             계절 변화는 흡수하지만 천천히 나빠지는 고장은 놓친다.
```

마지막 함정은 [5-7](5-7.md) 에서 다시 만난다.

## 자주 하는 실수

- **기준선을 안 만든다.** 그러면 AI 를 쓸 근거도 못 만든다.
- **재현율만 본다.** 정밀도를 같이 봐야 결론이 무너진다.
- **정확도 차이로 도입을 정당화한다.** 근거는 "통계가 못 하는 일"이다.
