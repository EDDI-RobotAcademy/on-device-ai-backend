# 3-1. 데이터를 처음으로 AI에게 먹여보자

## 문제

모델은 CSV 를 먹지 않는다. **고정된 모양을 가진 숫자 덩어리**를 먹는다.

그리고 그 덩어리를 만들 수 있는지는 학습을 3분 돌린 뒤가 아니라
**시작하기 전에** 확인해야 한다.

## 실습

```bash
pytest -m lesson_3_1 -s
```

## 무엇을 보게 되는가

```text
학습 준비 (run-cnn)
  데이터   : power-model
  구조     : CNN1D input=(30, 6) hidden=(16, 32) k=5 → 3 classes
  창       : length=30 stride=10 (겹침 67%) / FAULT 30% 이상 → OVERLOAD 50% 이상 → 그 외 NORMAL
  한 표본  : (30, 6)
  한 배치  : (32, 30, 6)  (22.5 KiB)

12,960행 → 창 1,294개 (length=30, stride=10, 겹침 67%)
  독립 표본 환산 431개 / 라벨 FAULT 50, NORMAL 1008, OVERLOAD 236

  train         905개  shape=(30, 6)   min= -7.127 max=  2.109 mean= -0.001 std= 1.000
  validation    194개  shape=(30, 6)   min= -7.127 max=  2.020 mean= -0.014 std= 1.006
  test          195개  shape=(30, 6)   min= -7.127 max=  2.062 mean=  0.110 std= 0.995
```

12,960행짜리 CSV 가 `(30, 6)` 짜리 표본 1,294개가 되었다.
**이 모양이 앞으로 모든 것을 결정한다.**

## 확인해야 하는 것 네 가지

### 1. 정규화가 실제로 걸렸는가

```text
train      mean= -0.001  std= 1.000
test       mean=  0.110  std= 0.995
```

train 평균이 0, 표준편차가 1 이면 정규화가 걸린 것이다.

그리고 **test 평균은 0 이 아니다.** 당연하다 — 통계를 train 에서만 뽑았기 때문이다
(실습 1-7). test 평균이 정확히 0 으로 나온다면 그게 누수다.

### 2. NaN 이 없는가

```python
assert summary.nan_count == 0
```

이걸 확인하지 않으면 학습 3분 뒤에 `loss=nan` 을 보게 된다.
그때는 원인이 데이터인지 학습률인지 구분할 수 없다.

### 3. 모양이 맞는가

```python
ShapeMismatch: 창 길이(30)와 모델 입력의 시간 축(60)이 다르다.
               학습은 돌아가고 배포할 때 터진다.
```

`Dataset` 이 만드는 모양과 모델이 기대하는 모양은 **계약**으로 맞춰져 있어야 한다.
안 맞으면 준비 단계에서 멈춘다.

### 4. 게이트를 통과했는가

```python
IllegalStateTransition: 게이트를 통과하지 않은 데이터로 학습을 시작할 수 없다:
                        모듈 1 · 학습 착수 판정, 모듈 2 · Data Quality Gate
```

**모듈 1과 2가 존재한 이유가 이 한 줄이다.**

데이터가 준비된 것과 승인된 것은 다르다.
`TrainingRun.prepare()` 는 `TrainingDataRef.gates_passed` 를 보고, 아니면 시작조차 하지 않는다.

## 배치 크기는 메모리를 결정한다

```text
표본 하나  : 180개 원소 × 4바이트 = 720바이트
배치 32    : (32, 30, 6)   22.5 KiB
배치 256   : (256, 30, 6)  180.0 KiB
```

모듈 4(최적화)에서 이 계산이 그대로 다시 쓰인다.
디바이스 메모리가 정해져 있으면, 배치 크기와 입력 크기 중 하나를 포기해야 한다.

## 설계 관점 — 세 Context 를 잇는다

`domain/model` 은 `domain/data` 도 `domain/data_quality` 도 **import 하지 않는다.**

```python
# application/model/training_data_mapper.py — Anti-Corruption Layer
def training_data_from(dataset: Dataset, assessment: QualityAssessment | None):
    ...
    return TrainingDataRef(
        ...,
        readiness_certified=dataset.status is DatasetStatus.READY,   # 모듈 1
        quality_gate_passed=assessment.status is AssessmentStatus.PASSED,  # 모듈 2
    )
```

세 Context 가 서로를 모르면서도, **게이트 통과 여부는 전달된다.**
그 사실만 원시 값(`bool`)으로 넘어간다.

이 규칙은 테스트가 지킨다.

```bash
pytest tests/test_architecture.py -k Bounded_Context
```

## 자주 하는 실수

- **바로 `model.fit()` 을 호출한다.** shape 오류, NaN, 라벨 불일치를 한꺼번에 만난다.
- **정규화 통계를 전체 데이터로 다시 계산한다.** 실습 1-7 에서 막은 누수가 여기서 되살아난다.
- **test 평균이 0 이 아니라고 "정규화가 안 됐다"고 판단한다.** 반대다.
