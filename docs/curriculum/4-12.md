# 4-12. 학습 중에 양자화를 가르쳐라

## 문제

[4-7](4-7.md) 에서 한 것은 **PTQ**(Post-Training Quantization)다.

```text
학습(FP32) → 변환(INT8) → 정확도 확인
```

장점이 명확하다. **학습 파이프라인을 안 건드린다.**
문제는 모델이 그 사실을 모른 채 배웠다는 것이다.

**QAT**(Quantization-Aware Training)는 순서를 바꾼다.

```text
학습(순전파에서 INT8 로 눌러 본다) → 변환(INT8)
```

학습 중에 눌린 값으로 손실을 계산하므로,
모델이 **눌려도 견디는 가중치**를 찾아간다.

## 실습

```bash
pytest -m lesson_4_12 -s
```

## 순서가 있다

```text
   비트     PTQ 정확도     QAT 회복
      8         1.000       +0.000
      4         1.000       +0.000
      3         1.000       +0.000
      2         0.833       +0.167
```

8비트에서는 아무 일도 안 일어난다.

```text
INFO QUANT_PTQ_SUFFICIENT
     PTQ 손실이 0.000 다.
     **이 정도면 QAT 를 도입할 이유가 없다** —
     학습 파이프라인을 하나 더 유지하는 비용은 재학습할 때마다 계속 나간다.
```

> **PTQ 를 먼저 재 보고, 부족할 때만 QAT 로 간다.**

## 무너지는 지점에서는 QAT 가 되찾는다

```text
[2비트로 누르면]
  기준선(FP32)  정확도 1.000
  PTQ (변환 후 누름)   정확도 0.833 (-0.167)  학습 0.0s
  QAT (배우면서 누름)  정확도 1.000 (+0.000)  학습 0.4s
```

```text
INFO QUANT_QAT_JUSTIFIED
     PTQ 가 0.167 를 잃었고 QAT 가 +0.167 를 되찾았다.
     **여기서는 QAT 를 도입할 근거가 있다.**
```

근거는 "정확도가 더 높다"가 아니라 **"얼마나 되찾는가"**다.

## QAT 의 전부는 세 줄이다

```python
q = round(w / scale)          # 격자에 올린다
q = clamp(q, -2**(b-1), ...)  # 표현 범위를 넘으면 자른다
w' = q * scale                # 다시 실수로 돌린다
```

이걸 **순전파에만** 넣고 역전파에서는 통과시킨다(straight-through).

## 가장 흔한 버그

`round()` 의 미분은 거의 모든 점에서 0이다. 그대로 두면 아무것도 안 배운다.
그리고 이런 구현도 같은 결과를 만든다.

```python
# 나쁜 예 — 계산 그래프가 끊긴다
layer.weight = nn.Parameter(fake_quantize(layer.weight, spec), requires_grad=False)
```

```python
# 좋은 방향 — functional 로 부른다
weight = fake_quantize(inner.weight, spec)
return F.conv1d(x, weight, inner.bias, ...)
```

**QAT 를 붙였는데 정확도가 그대로라면 이것부터 확인해야 한다.**
학습은 돌고 에러는 안 난다.

## 배율을 어디까지 쪼개는가

```text
채널별   PTQ 1.000
전체공통 PTQ 0.955
```

배율 하나로 전체를 누르면 **가장 큰 채널이 나머지를 다 눌러 버린다.**

## QAT 는 공짜가 아니다

```text
PTQ 학습 시간 : 0.00s (학습 없음)
QAT 학습 시간 : 0.42s
```

여기서는 1초 남짓이다. 실제 모델에서는 배로 든다.
**그리고 그 시간은 재학습할 때마다 든다** (모듈 5, 6).

## 자주 하는 실수

- **PTQ 를 안 재고 QAT 부터 한다.** 대개 필요 없다.
- **가중치에 대입하는 식으로 구현한다.** 아무것도 안 배운다.
- **배율을 전체 공통으로 잡는다.** 공짜에 가까운 이득을 버린다.
- **정확도가 조금 높다는 이유로 도입한다.** 파이프라인 비용이 영구히 남는다.
