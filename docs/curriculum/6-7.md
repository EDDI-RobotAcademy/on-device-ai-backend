# 6-7. 모델 Version을 Cloud에서 관리하라

## 문제

> **한 채널에 두 버전이 동시에 있을 수 없다.**

그것을 허용하는 순간 "지금 stable 이 뭐죠?"에 답할 수 없게 된다.

```text
canary    몇 대에만. 문제가 나도 몇 대다.
stable    전부에게. canary 를 통과한 것만 온다.
archived  더 이상 내보내지 않는다. **지우지는 않는다** — 롤백 대상일 수 있다.
```

## 실습

```bash
pytest -m lesson_6_7 -s
```

## canary 를 거치지 않으면 stable 로 못 간다

```text
[ILLEGAL_STATE_TRANSITION] v3.0.0: 'v3.0.0' 은 canary 를 거치지 않았다.
    몇 대에서 확인하지 않은 것을 전부에게 보내지 않는다.
```

이 규칙 하나가 **"급하니까 바로 전체 배포"를 막는다.**
그리고 급한 상황일수록 그 배포가 위험하다.

## 한 채널에 하나뿐이다

```text
승격 전 : canary=v2.0.0  stable=v1.0.0  archived=0개
승격 후 : canary=(없음)  stable=v2.0.0  archived=1개
```

```python
def with_promotion(self, version: str, channel: ReleaseChannel) -> ChannelState:
    """새 버전을 채널에 올린다. 있던 것은 밀려난다."""
```

stable 로 올라가면 canary 에서 빠진다.
같은 버전이 양쪽에 있으면 **canary 가 무엇을 시험하고 있는지 알 수 없다.**

## 밀려난 것을 지우지 않는다

```text
ARCHIVED = "ARCHIVED"
"""더 이상 내보내지 않는다. **지우지는 않는다** — 롤백 대상일 수 있다."""
```

[6-9](6-9.md) 에서 되돌릴 곳이 필요해진다.
지워 버리면 그때 돌아갈 데가 없다.

## 등록되지 않은 버전은 채널에 못 올린다

```text
[NOT_RELEASABLE] v9.9.9: 'v9.9.9' 은 이 플릿에 등록된 적이 없다.
```

채널은 이름표가 아니다. **실제로 있는 묶음을 가리켜야 한다.**

## 이 프로젝트에는 버전이 네 가지 있다

```text
모델 버전    mv-power-opt-cnn1d-s42   어떤 학습이 만든 가중치인가      (모듈 3)
결과물       TFLITE/FP16              어떤 형식으로 바꿨는가            (모듈 4)
배포 버전    v1, v2, v3               한 대의 배포 이력                 (모듈 5)
릴리스       v2.0.0                   플릿 전체의 카탈로그              (모듈 6)
```

**네 개가 다 다르다.** 그리고 각각이 다른 질문에 답한다.

```text
"어떤 데이터로 배웠죠?"        → 모델 버전
"플래시에 들어가나요?"          → 결과물
"어제 3시에 뭐가 돌았죠?"       → 배포 버전
"지금 stable 이 뭐죠?"          → 릴리스
```

## 승격은 사건으로 남는다

```text
ReleasePublished   언제 무엇이 등록됐는가
ReleasePromoted    언제 무엇이 어느 채널로 올라갔는가 (그리고 무엇이 밀려났는가)
```

**판정 결과보다 판정 기준의 변경이 중요하다** — 모듈 5-6 의 기준 재고정과 같은 이야기다.

## API

```http
POST /fleets/line3/channels
{"version": "v2.0.0", "channel": "CANARY"}
```

canary 를 안 거치고 STABLE 로 보내면 **409** 다.

## 자주 하는 실수

- **바로 stable 에 올린다.** 몇 대에서 확인하지 않은 것을 전부에게 보낸다.
- **한 채널에 여러 버전을 둔다.** "지금 뭐가 도는지" 못 답한다.
- **밀려난 릴리스를 지운다.** 되돌릴 곳이 없어진다.
- **버전 이름 하나로 네 가지를 다 부른다.** 질문마다 답이 달라야 한다.
